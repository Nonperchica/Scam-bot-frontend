# Senior Guard 🛡️

ระบบตรวจจับข้อความสแกมจาก LINE Chatbot เพื่อปกป้องผู้สูงอายุ

## Tech Stack

- **Frontend:** React + TypeScript + Vite
- **Styling:** Vanilla CSS (Dark Mode)
- **Charts:** Recharts
- **Icons:** Lucide React
- **Routing:** React Router DOM

## Getting Started

```bash
# ติดตั้ง dependencies
npm install

# รัน development server
npm run dev
```

## Project Structure

```
src/
├── assets/         # รูปภาพ, โลโก้
├── components/     # UI components (Sidebar, StatCard, ThreatTable)
├── layouts/        # Page layouts (MainLayout)
├── pages/          # Pages (Overview, ThreatLogs)
├── services/       # API service layer
├── types/          # TypeScript interfaces
├── utils/          # Utility functions
├── App.tsx         # Router setup
└── main.tsx        # Entry point
```
